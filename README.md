# Batuta

Organizador de casas: listas de tarefas, compras, notas e rotinas de limpeza num só lugar.

Projeto final de MC322 por Glayson, Heitor, João e Manuela.

# Requisitos

- JDK 17+ para rodar o Gradle. Se não houver um JDK 25 na máquina, o Gradle baixa ele automaticamente (thanks, foojay-resolver).

## Compilação e execução

Linux/macOS:

```
./gradlew build
./gradlew run
```

Windows:

```
gradlew.bat build
gradlew.bat run
```

A casa é salva em `house.xml`, na pasta de onde o programa é executado.
